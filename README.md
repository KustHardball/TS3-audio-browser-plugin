# Музыка ЛС !1–!20

Плагин для TeamSpeak 3 (64-bit, клиент 3.6+). По нажатию клавиши или сочетания отправляет выбранному человеку в личку текст `!1` … `!20`.

Клавиши обрабатывает сам TeamSpeak — тем же глобальным перехватом, что и «Нажать и говорить». Они срабатывают, когда игра в фокусе и окно TeamSpeak не активно.

## Установка

1. Закройте TeamSpeak.
2. Запустите `install.bat` (попросит права администратора)  
   или скопируйте `dist\music_pm_hotkeys.dll` в  
   `C:\Program Files\TeamSpeak 3 Client\plugins\`.
3. Запустите TeamSpeak. В **Инструменты → Плагины** включите **Музыка ЛС !1-!20**.

## Кому писать

Правый клик по боту (или любому человеку) в списке клиентов → **Назначить получателем команд !1-!20**.

Ник и Unique ID можно поправить кнопкой **Настройки** в том же окне плагинов. Файл настроек:

`%APPDATA%\TS3Client\music_pm_hotkeys.ini`

## Клавиши

**Инструменты → Опции → Горячие клавиши → Добавить.**

В списке действий плагина выберите, например, **Отправить !1 в личку**, нажмите нужную клавишу или сочетание и сохраните. Так же назначьте `!2` … `!20`.

Если у вас в этой игре работает «Нажать и говорить», будут работать и эти клавиши. Если игра глушит перехват, запустите TeamSpeak от имени администратора — тот же способ, что и для микрофона.

## Проверка без клавиши

В чате сервера:

```
/musicpm 1
```

Это отправит `!1` в личку. `/musicpm who` показывает, кому уходят команды.

## Сборка

Нужен 64-bit MinGW `gcc`. `build.bat` сам скачает заголовки TeamSpeak 3 Plugin SDK и соберёт `build\music_pm_hotkeys.dll`.
